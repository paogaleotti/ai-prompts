Contexto de lineamientos visuales corporativos de Southcom

Usar la siguiente paleta de colores como base de identidad visual:

- Primary green: #048C3F
- Secondary green: #0E5E3A
- Soft accent green: #7FBF9F
- Petroleum blue: #1F3C4D
- Dark gray: #2B2F33
- Medium gray: #6B7280
- White: #FFFFFF

Reglas de uso:
- La identidad visual debe transmitir profesionalismo, claridad, solidez técnica y sobriedad.
- Priorizar una estética limpia, moderna y corporativa.
- Usar los verdes como base principal de marca.
- Usar petroleum blue como color de apoyo institucional o técnico.
- Usar grises para textos secundarios, bordes, separación visual y elementos neutros.
- Usar blanco como base para fondos limpios y buena legibilidad.

Restricción semántica:
- Orange (#f59e0b) y Red (#ef4444) son colores semánticos reservados exclusivamente para alertas, advertencias, errores o estados críticos.
- Nunca usar orange o red con fines decorativos, estéticos o de identidad de marca.

Aplicación esperada:
- Estos lineamientos deben respetarse en imágenes corporativas, documentos, presentaciones, interfaces web y piezas visuales relacionadas con la marca.
- El resultado debe evitar una estética recargada, informal o excesivamente promocional.
- Debe privilegiarse una imagen seria, confiable, tecnológica y consistente.
